{%- comment -%} Overrides minima 2.5.1's _layouts/default.html — the version GitHub Pages pins. Everything outside the two-column block below is minima's own, kept verbatim so head, header and footer keep behaving the way the theme intends. A layout override rather than a different theme, deliberately: a theme is a dependency and this is a nav (list.md Phase 19). The nav is built from front matter — `group` and `nav_order` on every published page — and those two are not a second hand-maintained list. `CapabilityDescriptor.Group` already orders the settings surface, and DocumentationGateTests asserts that each capability page's front matter still matches the descriptor it belongs to. Change a capability's group and the test says which page to edit, the same way the schema gate already says which block to paste. index.md used to carry a table of the capabilities and their groups, by hand. It listed sixteen of the thirty-three by the time this was written, which is the argument for the nav being generated and for the table being gone. Grouping is by `group`; groups are ordered by the lowest `nav_order` in them, so the running order is the registry's own rather than alphabetical — which is the order the panel shows and the order a reader has some use for. {%- endcomment -%} {%- include head.html -%} {%- include header.html -%}
